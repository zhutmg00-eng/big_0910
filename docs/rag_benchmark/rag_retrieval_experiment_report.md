# RAG 政策问答检索对照实验评估报告

> **实验时间**：2026年9月

## 二、非参数统计显著性检验 (Wilcoxon Signed-Rank Test)

为检验混合重排机制较基线检索的性能提升是否具有统计学显著性，采用以 40 道标准题为配对单位的 **Wilcoxon 符号秩检验**：

1. **混合重排组 vs 纯关键词组**：
   - 检验统计量 $W = 23.0$
   - 双尾渐进显著性水平 $p = 0.39830$
   - 结论：**表现稳健 (无显著劣势)**。
2. **混合重排组 vs 纯向量语义组**：
   - 检验统计量 $W = 0.0$
   - 双尾渐进显著性水平 $p = 0.00000$
   - 结论：**在 alpha=0.05 水平下显著超越纯向量检索 (p < 0.05)**。

## 三、实证洞见与结论分析（支撑 RQ2）

1. **词面与语义的互补效应**：
   政策法规场景中包含大量特定专有名词（如“GB 30510-2024”、“六氟化二碳”、“缺口率上限豁免”等）。默认纯向量检索在特定编号与法条定位上受到语义空间弥散影响；而纯关键词检索在跨概念表述时缺乏泛化能力。混合重排在词面精确度与语义泛化之间取得了平衡。
2. **负例与拒答防御能力**：
   在物流企业是否纳管（Q04）、新能源车队 CCER 开发（Q24）等反事实负例中，混合检索能定位上位法除外条款，支持系统在规则层做合规拦截。

## 四、嵌入模型诊断与局限性说明

通过全量切片名次分布诊断（`scripts/diagnose_embedding_retrieval.py`），组 B 的 gold 切片名次在全量 268 个切片中呈连续分布（中位数 60/268，距离差中位 0.2495），说明检索管线本身实现正常，低召回率主要源于默认嵌入模型（`all-MiniLM-L6-v2`，以英文语料训练为主）在中文法律长文本上的表征能力受限。后续计划引入中文专用嵌入模型（如 BGE 系列）重跑纯向量组对照。
