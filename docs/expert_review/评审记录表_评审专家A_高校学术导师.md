## 二、定性评价意见与学术诊断

### 1. 核心学术优势（Strengths）
1. **研究范式脱离了“纯系统堆砌”的低水平内卷**：  
   项目团队没有停留在常见的“Streamlit 界面调 API 包装”，而是真正围绕三大科学问题（活动水平法误差来源 RQ1、垂直法规检索语义稀疏 RQ2、参数扰动敏感性机理 RQ3）组织实验，具备显著的学术研究深度。
2. **误差恒为正偏的发现具有重要实践价值**：  
   实证样本加权 MAPE 为 4.23%，且四大案例相对误差恒定为正（+1.66% ~ +7.27%），在学术上证明了基于行业标准因子的活动水平法能够作为“保守估计上限”，非常适合用于指导缺乏发票明细的物流中小企业进行情景对标。
3. **统计显著性检验逻辑扎实**：  
   针对 40 题标准库所开展的纯向量 vs 混合重排检验（Wilcoxon $W=0.0, p < 0.001$）揭示了通用 Embedding 在专业法规长尾实体中的弥散现象，具有鲜明的领域创新性。

### 2. 前期审校所提建设性意见（已采纳并在系统中落地）
- **学术建议 1**：建议在新能源车核算中，不仅保留 Scope 1 直接排放为零的口径，还需引入基于生态环境部最新公告的电网购电因子（Scope 2），计算“以电代油”的净减排贡献，否则容易受到评委对“电动车是否真正减碳”的质询。  
  *(团队采纳情况：已在 `src/engine/indirect_emission.py` 中完整集成 2025年第47号公告的全国平均、化石电力及 31 省市最新因子库，并完成回归测试。)*
- **学术建议 2**：交通主管部门对货运企业的考核核心看“货物周转量（万吨公里）碳强度（gCO2/t·km）”，建议在总量基础上增加周转量强度指标。  
  *(团队采纳情况：已实现货运周转量与单位周转量碳强度对标计算，量纲定义严谨。)*
