# 敏感性分析报告（实载率偏移 -0.30~+0.15 × 里程缩放 ±20%）

- 基线全样本 MAPE：4.23%（与 real_fleet_validation_report 一致）
- 扫描区间：MAPE 3.04% ~ 29.80%（50 种组合）
- 中位数 MAPE：14.51%；超过 10% 的组合 30/50
- 最坏组合：MAPE 29.80%（实载率偏移 -0.30，里程 ×1.2）

## 结论分析

1. **基线可复现**：MAPE 4.23% 与验证报告一致，四案例相对偏差 +3.84%/+1.66%/+4.17%/+7.27%。
2. **误差方向在基准附近保持正偏**（模型偏保守），适合合规预警用途。
3. **年均里程是一阶主导敏感因子**：由于模型输出对里程呈一阶线性关系，±20% 的里程偏差几乎 1:1 转化为约 ±20 个百分点的输出偏差；实载率净效应约为 1.3 个百分点。
4. **工程部署建议**：实际应用中必须优先获取车辆实测里程读数（如车载终端、年检记录），实载率则可采用区间输入并结合保守偏置。
