大创中期答辩科研实证展板 — 物流碳排放与减排决策系统

定位：大学生创新创业训练计划科研原型成果展板 | 核心原则：以“研究问题 (RQ) + 实证检验 + 统计显著性”组织答辩链条，杜绝功能堆砌与法定履约夸大。

RQ1: 数据有限条件下活动水平估算法的精度与一致性核验

样本集: 顺丰 / 中通 / 京东 / 区域冷链 (合计 51,990 辆) 案例等权 MAPE = 4.23% (加权 2.38%) 偏差区间: [+1.66%, +7.27%]
实证发现：相较于依赖详尽燃油发票的能源台账法，基于“车型×因子×里程×保守偏置”的活动水平算法案例等权平均偏差为 4.23%、加权为 2.38%；4 组场景偏差方向一致为正（偏保守估计）。需同时说明：移除满载率偏置后等权 MAPE 反降至 3.54%，故该偏置的价值在于保守性而非精度。

RQ2: 双碳政策法规检索中标题重排机制的有效性与非参数检验

自建评测集: 40 题标准基准 (含 4 负例) 全量知识库: 281 Chunks（运行时实测） Wilcoxon 检验: p < 0.001***
实证发现：同一语料（39 份政策文件 / 281 切片）与同一中文嵌入（bge-small-zh-v1.5）条件下，纯关键词 MRR 0.4879 / R@10 70.0%，纯向量 0.2589 / 57.5%，三路加权融合 0.4920 / 80.0%。融合相对纯向量显著（W=76.0, p=0.0023, Holm 0.0138），相对纯关键词不显著（W=42.0, p=0.320, Holm 0.961）。4 道反事实负例题的检索命中率为 2/4（50%）——检索层不实现拒答，早期“拒答率 75%/100%”属循环定义，已撤回。

RQ3: 运营参数扰动下的敏感性矩阵与不确定性边界

扰动网格: 实载率 (-0.30 ~ +0.15) × 里程 (±20%) 误差扫描区间: [3.04%, 29.80%] (中位数 14.51%)
实证发现：参数扰动表明年均里程是一阶主导因子，但效应强不对称——+20% 使 MAPE 上升 +20.72~+21.63 pp，−20% 仅上升 +5.30~+13.55 pp；实载率引起的 MAPE 变化约 4.59 pp（行内极差 3.67~5.50 pp），不是可跨里程倍数通用的常数。全网格 50 组中 30 组超过 10%，中位数 14.51%。
