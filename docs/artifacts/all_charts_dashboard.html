大创中期答辩科研实证展板 — 物流碳排放与减排决策系统

定位：大学生创新创业训练计划科研原型成果展板 | 核心原则：以“研究问题 (RQ) + 实证检验 + 统计显著性”组织答辩链条，杜绝功能堆砌与法定履约夸大。

RQ1: 数据有限条件下活动水平估算法的精度与一致性核验

样本集: 顺丰 / 中通 / 京东 / 区域冷链 (合计 51,990 辆) 等权 MAPE = 4.23% (加权 2.38%) 偏差区间: [+1.66%, +7.27%]
实证发现：相较于依赖详尽燃油发票的能源台账法，基于“车型×因子×里程×保守偏置”的活动水平算法案例等权平均偏差为 4.23%、加权为 2.38%；且4组场景均呈现稳定的正偏特征（偏保守估计），具备良好的工程实用价值。

RQ2: 双碳政策法规检索中标题重排机制的有效性与非参数检验

自建评测集: 40 题标准基准 (含 4 负例) 全量知识库: 37 份法规 (268 Chunks) Wilcoxon 检验: p < 0.001***
实证发现：默认通用向量模型在处理“GB 30510-2024”、“六氟化二碳”、“豁免上限”等高度专业词汇时表现出明显的语义空间弥散 (MRR 仅 0.0411)；混合重排机制将 MRR 提升至 0.5036、Recall@10 提升至 75.00%，且在负例拒答（如物流企业不属于全国履约主体）中保持 75% 的拒答准确率。

RQ3: 运营参数扰动下的敏感性矩阵与不确定性边界

扰动网格: 实载率 (-0.30 ~ +0.15) × 里程 (±20%) 误差扫描区间: [3.04%, 29.80%] (中位数 14.52%)
实证发现：参数扰动表明年均里程是一阶主导因子（±20% 里程直接转化约 ±20 pp 误差），实载率净效应约 1.3 pp；全网格误差在 3.04% 至 29.80% 之间收敛，量化界定了输入数据不确定时的误差边界。
