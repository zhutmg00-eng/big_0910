大创中期答辩科研实证展板 — 物流碳排放与减排决策系统

定位：国家级/省级大学生创新创业训练计划科研原型成果展板 | 核心原则：以“研究问题 (RQ) + 实证检验 + 统计显著性”组织答辩链条，杜绝功能堆砌与法定履约夸大。

RQ1: 数据有限条件下活动水平估算法的精度与误差根因溯源

样本集: 顺丰 / 中通 / 京东 / 生鲜冷链 全样本加权 MAPE = 4.23% 误差方向: 恒为正偏 (+2.88% ~ +5.20%)
实证发现：相较于依赖详尽燃油发票的能源台账法，基于“车型×因子×里程×满载率惩罚”的活动水平算法平均误差仅 4.23%；且所有场景均呈现稳定的轻微正偏（保守估计），绝不低估排放，具备出色的工程可用性。

RQ2: 双碳政策法规检索中标题重排机制的有效性与非参数检验

自建评测集: 40 题标准基准 (双盲审校 Kappa=1.0) 全量知识库: 37 份法规 (268 Chunks) Wilcoxon 检验: p < 0.001***
实证发现：纯向量语义模型在处理“GB 30510-2024”、“六氟化二碳”、“豁免上限”等高度专业词汇时表现出严重的语义稀疏 (MRR 仅 0.0411)；混合重排机制将 MRR 提升至 0.5036、Recall@10 提升至 75.00%，且在负例拒答（如物流企业不属于全国履约主体）中保持 75% 的高保真度。

RQ3: 运营参数扰动下的敏感性矩阵与不确定性边界

扰动网格: 满载率 (-20% ~ +20%) × 里程 (-20% ~ +20%) 误差闭环区间: [+1.22%, +7.80%]
实证发现：在大幅度参数波动下，模型误差始终保持在 +1.22% 至 +7.80% 的可控狭窄区间内，量化并证明了满载率基准值（默认 75%）是主要但完全可控的误差来源。
