# 系统架构文档

```
┌─────────────────────────────────────────────────────────┐
│              Streamlit 前端 (用户交互层)                  │
│  车队数据输入 │ 排放情景看板 │ 政策资料问答              │
└────────┬────────────┬──────────────┬────────────────────┘
         │            │              │
         ▼            ▼              ▼
┌─────────────────────────────────────────────────────────┐
│           FastAPI 后端 (API + 业务逻辑层)                │
│                                                         │
│  ┌──────────────────┐  ┌──────────────────────────┐    │
│  │ 碳排放计算引擎    │  │ RAG 政策解析引擎          │    │
│  │ • 排放因子换算    │  │ • 知识库(ChromaDB)       │    │
│  │ • 模拟预算比较    │  │ • 语义检索(向量匹配)     │    │
│  │ • 碳价情景换算    │  │ • LLM调用(Prompt引擎)    │    │
│  └──────────────────┘  └──────────────────────────┘    │
│                                                         │
│  ┌──────────────────────────────────────────────────┐  │
│  │          共享数据层 (企业碳画像)                    │  │
│  └──────────────────────────────────────────────────┘  │
└────────┬────────────┬──────────────┬────────────────────┘
         │            │              │
         ▼            ▼              ▼
┌─────────────────────────────────────────────────────────┐
│                    数据存储层                            │
│  ChromaDB │ JSON/CSV │ 政策文档(Markdown缓存)           │
└─────────────────────────────────────────────────────────┘
```

## 核心设计原则

1. **计算与推理分离** — 碳排放量用规则引擎（确定性），政策解读用LLM（概率性）
2. **渐进式开发** — 每个阶段产出可独立运行、可演示
3. **MVP优先** — 先打通"输入车队→输出直接运营排放和减排情景"这条最小链路
4. **模拟数据先行** — 前6个月用公开数据和模拟参数

## 模块说明

### 碳排放计算引擎 (`src/engine/`)
- `emission_factors.py` — 排放因子数据库（查表）
- `calculator.py` — 碳排放基线计算（数学公式）
- `quota.py` — 模拟碳预算差额估算（不是法定配额）
- `carbon_price.py` — 碳价对标情景换算（不是履约成本或实际收益）

### RAG政策助手 (`src/rag/`) — 自研RAG链路（未使用LangChain）
- `parser.py` — 文档解析(PDF/DOCX/HTML) + 清洗 + 切分
- `vector_store.py` — 向量知识库管理（ChromaDB优先，TF-IDF fallback）
- `bm25.py` — jieba 分词 Okapi BM25 检索路
- `embeddings.py` — 嵌入模型选择与本地缓存
- `reranker.py` — 交叉编码器精排（默认关闭，CPU 上指标反而下降）
- `generator.py` — Prompt模板 + LLM调用（含错误处理与降级）

> 政策语料不通过自动爬虫获取：`data/policy_docs/` 由人工从各官网「信息公开」
> 栏目下载后整理，来源与抓取时间记录在文件的 `来源:` 与 `抓取时间:` 字段。
> 早期存在过 `crawler.py`，因始终未接入主流程、且使用浏览器 UA 且未检查
> robots.txt，已删除（见 `docs/迭代队列.md` I-1）。

### API层 (`src/api/`)
- `main.py` — FastAPI应用入口
- `POST /api/calculate` — 碳排放计算
- `POST /api/ask` — 政策问答
- `GET /api/vehicle-types` — 车型列表
- `GET /api/kb/stats` — 知识库统计
- `POST /api/kb/ingest` — 导入政策文档

### 前端 (`src/ui/`)
- `app.py` — Streamlit主入口
- 页面：首页、碳排放盘点、政策顾问、排放因子表、生成报告、减排分析
