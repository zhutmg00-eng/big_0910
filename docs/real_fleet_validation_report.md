# 物流车队碳排放核算模型实证验证与误差分析报告

> **项目名称**：物流碳排放与减排情景决策助手  
> **所属阶段**：大创 Phase 4/5 实证验证与中期汇报成果  
> **最后更新**：2026年8月  
> **研究团队**：陈铭浩、张可为、王逸贤（指导教师：汪晓霞）  

---

## 摘要

为克服物流企业（尤其是中小型物流车队）缺乏专业碳核算工具与详细能源台账的困难，本项目研发了基于“自下而上活动水平法（Activity-based Method）”的轻量化直接运营排放测算模型。为严谨验证模型在数据有限条件下的可靠性与可解释性，本项目从**顺丰控股、中通快递、京东物流**等头部上市企业公开可持续发展报告（ESG）以及**G7易流《公路货运碳账本》/ 智慧货运中心（SFC）**权威行业实测数据库中，构建了涵盖“全国综合干支、长途重载甩挂、绿色仓配一体化、区域冷链城配”4 大典型场景的真实车队基准数据集。

实证结果表明：本模型测算的直接运营排放量与企业实际能源消耗台账（Fuel-based）具有高度一致性，**4 组案例全样本平均绝对相对误差（MAPE）为 4.23%，单样本最大相对误差为 +7.27%**（注：案例数 n=4，属小样本验证，结论需结合误差根因分析与敏感性分析看待）。满载率惩罚调整机制有效拟合了低满载率及空驶工况带来的单耗上浮。本报告为大创中期答辩提供了坚实的实证数据支撑与误差解释链条。

---

## 一、 实证研究背景与核心科学问题

### 1.1 研究背景
在“双碳”目标与“十五五”绿色低碳转型背景下，道路货运物流占我国交通运输领域碳排放近 80%。然而，多数中小型物流企业仅掌握车队车辆数、年均里程及大致满载率等基础活动数据，缺乏完备的燃油进销存台账与碳核算专业能力。

### 1.2 核心研究问题 (Research Questions)
1. **RQ1（模型可靠性）**：在仅输入车型、车辆数、年均里程与满载率的前提下，自下而上活动水平估算模型能否逼近企业真实燃料台账核算结果？
2. **RQ2（误差边界与来源）**：估算误差在不同业务场景（干线甩挂 vs 同城冷链）下的分布规律是什么？误差的主要物理诱因何在？
3. **RQ3（修正机制有效性）**：引入满载率调整函数 $LF_i = 1 + 0.15 \times (0.75 - l_i)$ 能否有效捕捉低满载率带来的效率惩罚？

## 三、 核算方法学对比与数学推导

```
  ┌─────────────────────────────────────────────────────────────┐
  │ 方法一：自下而上活动水平法（本系统模型算法 E_model）        │
  │ 输入：车型 n_i、里程 d_i、排放因子 EF_i、满载率 l_i         │
  │ 公式：E_model = Σ (n_i × d_i × EF_i × LF_i) / 1000          │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
                            [ 实证对比 ] ─── 相对误差 δ = (E_model - E_fuel) / E_fuel
                                 │
  ┌──────────────────────────────┴──────────────────────────────┐
  │ 方法二：自上而下企业能源台账法（真实基准 E_fuel）            │
  │ 输入：柴油升数、汽油升数、LNG公斤数                         │
  │ 公式：E_fuel = Σ (燃料消耗量_j × 单位体积直接排放因子_j) / 1000│
  └─────────────────────────────────────────────────────────────┘
```

### 3.1 转换系数与标准依据
依据 IPCC 2006/2019 Refinement 移动源燃烧指南与国家标准 GB/T 32150，实证采用的基准折算因子如下：
- **车用柴油**：$2.730 \text{ kg CO}_2/\text{L}$（折合 $3.250 \text{ tCO}_2/\text{t柴油}$，低位发热量 $42.652 \text{ GJ/t}$，含碳量 $20.2 \text{ tC/TJ}$，氧化率 $98\%$）；
- **车用汽油**：$2.310 \text{ kg CO}_2/\text{L}$；
- **液化天然气 (LNG)**：$2.690 \text{ kg CO}_2/\text{kg}$；
- **电网电力 (间接)**：$0.5306 \text{ kg CO}_2/\text{kWh}$（生态环境部公告2025年第47号发布的2023年全国电网平均二氧化碳排放因子）。

> **口径声明（必读）**：E_fuel 为按**披露燃料消耗量 × IPCC/GB/T 32150 折算因子**复算的能源台账值；E_baseline 为**构建基准时登记的台账基准值**，二者口径相同、理应相等。实际核验发现：Case 1/2/4 两者逐位吻合，Case 3（京东）基准值 79,800 比复算值 79,095 高 0.89%，属已知的内部不一致，已在 `benchmark_fleets.json` 的 `field_semantics` 中登记。
>
> **重要**：E_baseline **不是从企业报告中摘录的原始披露值**，而是课题组按上述因子复算得到（Case 1/2/4 已逐位验证；课题组未能获取企业报告原文页码，故不以"企业披露值"表述）。因此本节的误差是**"活动水平模型 vs 燃料台账口径"的一致性检验**，其参照系是燃料消耗量而非企业披露的排放数字——这一点必须与结论一起陈述，不能表述为"模型与企业披露值吻合"。
>
> 由此产生的方法学后果：本检验**部分自参照**——模型与台账共用同一套排放因子换算标准，二者差异主要来自"用里程推算燃料量"与"直接用燃料量"的口径差，这是本文真正检验的对象；但它**不能**证明所用排放因子本身与企业的实际因子一致。案例 3 的 +0.89% 内部不一致即为该局限的直接体现。

## 五、 误差根因深度剖析 (Error Root Cause Analysis)

实证结果显示，模型预测值与真实台账存在平均 $+4.23\%$ 的微小正偏差（偏保守估计），深入分析其物理诱因如下：

### 5.1 甩挂运输与高速工况的节油增效（Case 2 仅 +1.66%）
中通快递长途干线车队采用集约化大运力甩挂车（49t 以上），且 $85\%$ 以上里程处于高速公路巡航工况。甩挂技术显著降低了单位吨公里的风阻与单耗，实际百公里油耗优化至约 $28.5\text{ L/100km}$，使得基于标准工况因子测算的 $E_{\text{model}}$ 仅略高于真实台账 $1.66\%$，验证了模型在长途重载干线场景的高精确度。

### 5.2 城市工况拥堵与返程空驶（Case 4 偏差 +7.27%）
Case 4 为典型的冷链商超同城配送车队，其特点为：
1. **多频次启停与拥堵**：城区红绿灯频繁，平均车速较低；
2. **单向物流空驶**：去程送货（满载率约 $80\%$），返程空驶（满载率 $0\sim 20\%$），综合满载率仅 $58\%\sim 60\%$；
3. **冷机额外能耗**：车载制冷压缩机消耗柴油。
本模型设置的满载率调整系数 $LF_i$ 增加了 $+29.17\text{ tCO}_2\text{e}$ 的修正量，方向完全契合实际能耗上升趋势；剩余约 $7\%$ 的微差主要源于冷机独立耗油与拥堵怠速。

### 5.3 新能源车规模化替代的直接降碳效应（Case 1 & Case 3）
在顺丰与京东案例中，新能源物流车数量占比均超 $40\%\sim 55\%$。在当前“直接运营排放”核算边界下，纯电车直接排放记为 0，使得化石燃料总排放大幅压降。同时，本研究测算了其购电间接排放（顺丰电耗折合间接排放约 3.83 万吨，京东约 2.74 万吨），为后续升级“全生命周期/范围二购电排放”预留了完整的接口。

   - 严格区分“直接运营排放”与“购电间接排放/全生命周期”，坚持科研模拟预算口径，保持学术审慎与规范性。
